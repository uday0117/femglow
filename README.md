# FemGlow 🌸

**Your Personal Period Companion**

FemGlow is a privacy-focused period tracking and women's health application built with Flutter. Track your menstrual cycle, symptoms, and moods while keeping all your data private and secure on your device.

## ✨ Features

- 📅 **Period Tracking** - Log period start and end dates with flow intensity
- 🔮 **Cycle Predictions** - Get accurate predictions for upcoming periods and fertile windows
- 💊 **Medication Reminders** - Set reminders for birth control and other medications
- 📊 **Health Insights** - View detailed statistics and trends of your cycle
- 😊 **Mood Tracking** - Monitor daily moods and emotional patterns
- 🩺 **Symptom Logging** - Track physical and emotional symptoms
- 🔒 **Privacy First** - All data stored locally on your device, never on cloud servers
- 🌙 **Dark Mode** - Comfortable viewing in any lighting condition

## 🔐 Privacy & Security

FemGlow takes your privacy seriously:
- ✅ All data stored locally on your device
- ✅ No account registration required
- ✅ No data transmission to external servers
- ✅ No tracking or analytics
- ✅ No ads or third-party services
- ✅ Complete control over your data

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (^3.10.4)
- Dart SDK
- Android Studio / Xcode (for mobile development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/uday0117/femglow.git
cd femglow
```

2. Install dependencies:
```bash
flutter pub get
```

3. Run the app:
```bash
flutter run
```

## 🏗️ Built With

- **Flutter** - UI framework
- **GetX** - State management and navigation
- **GetStorage** - Local data persistence
- **Table Calendar** - Calendar widget
- **Flutter Local Notifications** - Reminder notifications
